# TraumaSense AI Demo

A self-contained, responsive dashboard prototype for trauma-informed support intake and case triage.

## Run locally

Open `index.html` in a browser, or run a local static server:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Prototype capabilities

- Sample assessment dashboard with search and risk filters
- Consent-gated intake form and a transparent, heuristic-only demo score
- Human-reviewed support suggestions and CSV export
- Responsive layout and multilingual language selection

## Important limitations

This is a front-end demonstration only. Its sample cases and simple scoring heuristic are not clinical assessments, validated AI, or suitable for real-world decisions. It does not analyze speech or audio, transmit or persist case data, or contact emergency services. Never enter real personal or case information. Production use would require validated clinical oversight, secure infrastructure, privacy and consent controls, accessibility and language testing, and approved emergency-response procedures.
